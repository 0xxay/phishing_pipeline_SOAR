================================================================================
PIPELINE STAGES EXPLAINED
================================================================================

STAGE 1: INGEST
  Polls Gmail for emails labeled "phishing"
  Extracts email body, headers, attachments
  -> pipeline/ingest/gmail_poller.py

STAGE 2: EXTRACT
  Finds URLs, IPs, domains, hashes in email text
  Computes MD5/SHA256 of attachments
  Parses headers for security analysis
  -> pipeline/extract/

STAGE 3: ENRICH (Parallel)
  VirusTotal: URL/hash reputation (detection counts)
  AbuseIPDB: IP abuse confidence (0-100%)
  URLScan.io: URL screenshots and verdicts
  -> pipeline/enrich/

STAGE 4: DECIDE
  Sends all data to GPT-4o for analysis
  Falls back to heuristic scoring if GPT unavailable
  Returns: MALICIOUS / SUSPICIOUS / CLEAN + confidence + MITRE ATT&CK tactic
  -> pipeline/decide/score_aggregator.py

STAGE 5: RESPOND
  MALICIOUS -> Block IOCs + escalate to TheHive
  SUSPICIOUS -> Alert analyst via Slack
  CLEAN -> Log as false positive
  -> pipeline/respond/

STAGE 6: CLOSE
  Create TheHive case with IOCs as observables
  Send Slack summary to analyst
  -> pipeline/close/

================================================================================
TROUBLESHOOTING
================================================================================

Gmail authentication failed
  -> Run: python -c "from pipeline.ingest.gmail_poller import setup_gmail_oauth; setup_gmail_oauth()"

No verdicts being generated
  -> Check OPENAI_API_KEY is set in .env
  -> The pipeline falls back to heuristic scoring if GPT-4o fails

API key errors (403, 401)
  -> Verify the key is correct in .env
  -> Check the API service is accessible

TheHive/Slack not receiving data
  -> Check THEHIVE_URL, THEHIVE_API_KEY
  -> Check SLACK_WEBHOOK_URL is correct
  -> Make sure services are running

For more help, see README.md Troubleshooting section.
